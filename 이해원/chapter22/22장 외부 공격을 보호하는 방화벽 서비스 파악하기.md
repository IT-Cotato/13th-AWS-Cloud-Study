# 1. 외부 공격을 보호하는 방화벽 서비스, AWS WAF란?

> **AWS Web Application Firewall**
https://aws.amazon.com/ko/waf/
> 

AWS에서는 허용하지 않는 사용자의 접근을 차단하기 위해 보안 그룹을 제공하고 있다.

사용자가 개발한 애플리케이션을 외부 공격으로부터 보호하려면 보안 그룹만으로 부족하다.

AWS WAF는 아마존 클라우드프론트, 애플리케이션 로드 밸런서와 같은 서비스에 연결할 수 있는 서비스로 웹 애플리케이션에 대한 공격을 방어하는 데 효과적이다.

# 2. AWS WAF 살펴보기

### 동작 원리

1. 로드 밸런서를 통해 EC2 인스턴스 접근 시도
2. 허용하는 요청이라면 AWS WAF에서 해당 요청이 악의적인 공격인지 검토
3. 모든 요청/대응은 클라우드워치를 통해 로깅, S3에 로그를 보존해 관리 가능
4. AWS WAF 검토 결과 문제가 없다면 정상적으로 요청

### 패턴

1. 클라우드프론트가 OAI로 S3 설정하는 경우
    - 클라우드프론트에 AWS WAF를 설정해 특정 IP로부터의 접근 차단/허용, 외부 공격 탐지/방어

2. 로드 밸런서와 클라우드프론트로 운용하는 환경

- 클라우드프론트에만 AWS WAF 설정
- 둘 다 AWS WAF 설정 → 보안 강화
- 대부분의 트래픽이 클라우드프론트를 통해 유입된다면, 클라우드프론트에만 적용해도 충분
- 둘 다에 설정하면 비용 증가

## 2.1 AWS WAF의 주요 5가지 기능

**애플리케이션에 대한 공격 방어**

**IP 제한으로 인한 무단 액세스 차단**

**DDoS 공격 대책**

**악의적인 봇 대책**

**계정의 무단 로그인 방지**

## 2.2 AWS WAF의 관리형 규칙

관리형 규칙을 설정해 방어하고자 하는 특정 유형의 악의적인 트래픽을 필터링하고 차단할 수 있다.

| 규칙명 | 용도 | 용량 | 비고 |
| --- | --- | --- | --- |
| Admin protection | 외부 액세스를 차단하고 관리 페이지를 보호하는 규칙 | 100 | 환경에 따라 선택 |
| Amazon IP reputation list | 아마존 내부 위협 인텔리전스를 기반으로 만든 규칙 | 25 | **필수로 도입 권장** |
| Anonymous IP list | IP 주소, 사용자의 신원을 난독화할 수 있는 서비스를 사용해 액세스를 차단할 수 있는 규칙 | 50 | 환경에 따라 선택 |
| Core rule set | 일반 웹 애플리케이션에 적용하는 규칙 | 700 | **필수로 도입 권장** |
| Known bad inputs | 무단 액세스 및 취약성 악용과 관련된 입력 패턴을 차단하는 규칙 | 200 | **필수로 도입 권장** |
| Linux operating system | 리눅스 취약점과 관련된 공격을 방지하는 규칙 | 200 | OS에 맞추어 선택 |
| PHP application | PHP 함수를 악용하는 무단 액세스 또는 PHP의 취약성을 찌르는 공격을 차단하는 규칙 | 100 | 환경에 따라 선택 |
| POSIX operating system | POSIX 및 POSIX 호환 운영체제 취약점과 관련된 공격을 방어하는 규칙 | 100 | OS에 맞추어 선택 |
| SQL database | SQL 데이터베이스의 악용을 방지하는 규칙 | 200 | **필수로 도입 권장** |
| Windows operating system | 윈도우 취약점 악용을 방지하는 규칙 | 200 | OS에 맞추어 선택 |
| WordPress application | 워드프레스 취약점을 악용하는 무단 액세스를 차단하는 규칙 | 100 | 환경에 따라 선택 |
- 위 규칙들은 무료
- 각 규칙마다 용량을 가지고, 설정할 수 있는 규칙 최대 용량은 5000WCU
    
    > web ACL capacity units
    > 

## 2.2 AWS WAF의 커스텀 규칙

- IP 세트: 특정 IP 요청에 대한 허용/차단과 같은 액션
- 규칙 빌더: 규칙 작성, AND/OR 선택, 검사 필드 선택 or 조건 선택해 규칙 생성
- 규칙 그룹: 작성한 규칙을 담을 수 있는 독자적인 규칙 그룹

# 3. AWS WAF 활용하기

- WAF.yml
    
    ```yaml
    AWSTemplateFormatVersion: "2010-09-09"
    Description: AWS WAF WebACL 
    # ------------------------------------------------------------
    # Input Parameters
    # ------------------------------------------------------------
    Parameters:
      SystemName:
        Description: "System name of each resource names."
        Type: String
        Default: "gr"
      EnvName:
        Description: "Environment name of each resource names."
        Type: String
        Default: "product"
    # ------------------------------------------------------------#
    # Create WAF
    # ------------------------------------------------------------# 
    Resources:
      WebACL:
        Type: AWS::WAFv2::WebACL
        Properties:
          DefaultAction:
            Allow: {}
          Scope: CLOUDFRONT
          Description: WebACL
          Name: !Sub ${SystemName}-${EnvName}-ACL01
          VisibilityConfig:
            CloudWatchMetricsEnabled: true
            MetricName: !Sub ${SystemName}-${EnvName}-WebACLMetrics
            SampledRequestsEnabled: true
          Rules:
            - Name: AWS-AWSManagedRulesAmazonIpReputationList
              Priority: 0
              OverrideAction:
                Count: {}
              Statement:
                ManagedRuleGroupStatement:
                  VendorName: AWS
                  Name: AWSManagedRulesAmazonIpReputationList
              VisibilityConfig:
                CloudWatchMetricsEnabled: true
                MetricName: AWSManagedRulesAmazonIpReputationList
                SampledRequestsEnabled: true
            - Name: AWS-AWSManagedRulesSQLiRuleSet
              Priority: 1
              OverrideAction:
                Count: {}
              Statement:
                ManagedRuleGroupStatement:
                  VendorName: AWS
                  Name: AWSManagedRulesSQLiRuleSet
              VisibilityConfig:
                CloudWatchMetricsEnabled: true
                MetricName: AWSManagedRulesSQLiRuleSet
                SampledRequestsEnabled: true
            - Name: AWS-AWSManagedRulesKnownBadInputsRuleSet
              Priority: 2
              OverrideAction:
                Count: {}
              Statement:
                ManagedRuleGroupStatement:
                  VendorName: AWS
                  Name: AWSManagedRulesKnownBadInputsRuleSet
              VisibilityConfig:
                CloudWatchMetricsEnabled: true
                MetricName: AWSManagedRulesKnownBadInputsRuleSet
                SampledRequestsEnabled: true
    # ------------------------------------------------------------#
    # Create WAF Log Bucket
    # ------------------------------------------------------------# 
      WAFLogBucket:
        Type: "AWS::S3::Bucket"
        Properties:
          BucketName: !Sub aws-waf-logs-${SystemName}-${EnvName}-acl01
          PublicAccessBlockConfiguration:
            BlockPublicAcls: true
            BlockPublicPolicy: true
            IgnorePublicAcls: true
            RestrictPublicBuckets: true
          LifecycleConfiguration:
            Rules:
              - Id: !Sub aws-waf-logs-${SystemName}-${EnvName}-acl-logs-lifecycle
                Status: Enabled
                ExpirationInDays: 365
          Tags:
            - Key: Name
              Value: !Sub aws-waf-logs-${SystemName}-${EnvName}-acl01
    # ------------------------------------------------------------#
    # WAF Logging Configuration
    # ------------------------------------------------------------# 
      WAFLoggingConfiguration:
        Type: 'AWS::WAFv2::LoggingConfiguration'
        Properties:
          ResourceArn: !GetAtt WebACL.Arn
          LogDestinationConfigs:
            - !GetAtt WAFLogBucket.Arn
    #------------------------------------------------------------
    # Output Parameters
    #------------------------------------------------------------
    Outputs:
    #WebACL
      WebACL:
        Value: !Ref WebACL
        Export:
          Name: WebACL
    #WebACL Arn
      WebACLArn:
        Value: !GetAtt WebACL.Arn
        Export:
          Name: WebACLARN
    #S3 Log Bucket
      WAFLogBucket:
        Value: !Ref WAFLogBucket
        Export:
          Name: WAFLogBucket
    #S3 Log Bucket Arn
      WAFLogBucketArn:
        Value: !GetAtt WAFLogBucket.Arn
        Export:
          Name: WAFLogBucketARN
    ```
    
- CloudFront.yml
    
    ```yaml
    AWSTemplateFormatVersion: "2010-09-09"
    Description: Create CloudFront & S3
    # ------------------------------------------------------------
    # Input Parameters
    # ------------------------------------------------------------
    Parameters:
      SystemName:
        Description: "System name of each resource names."
        Type: String
        Default: "gr"
      EnvName:
        Description: "Environment name of each resource names."
        Type: String
        Default: "product"
      BucketName:
        Description: "Bucket name."
        Type: String
        Default: "bucket"
    # ------------------------------------------------------------#
    # Create S3 Bucket
    # ------------------------------------------------------------# 
    Resources:
      S3Bucket:
        Type: AWS::S3::Bucket
        Properties:
          BucketName: !Sub ${SystemName}-${EnvName}-${BucketName}
          PublicAccessBlockConfiguration:
            BlockPublicAcls: true
            BlockPublicPolicy: true
            IgnorePublicAcls: true
            RestrictPublicBuckets: true
          Tags:
            - Key: Name
              Value: !Sub ${SystemName}-${EnvName}-${BucketName}
            - Key: Env
              Value: !Sub ${EnvName}
      BucketPolicy:
        Type: "AWS::S3::BucketPolicy"
        Properties:
          Bucket: !Ref S3Bucket
          PolicyDocument:
            Statement:
              - Effect: Allow
                Principal:
                  Service: cloudfront.amazonaws.com
                Action: "s3:GetObject"
                Resource: !Sub ${S3Bucket.Arn}/*
                Condition: 
                  StringEquals:
                    AWS:SourceArn: 
                      - !Join 
                        - ''
                        - - !Sub 'arn:aws:cloudfront::${AWS::AccountId}:distribution/'
                          - !Ref CloudFrontDistribution
    # ------------------------------------------------------------#
    #  CloudFront
    # ------------------------------------------------------------#
      CloudFrontOriginAccessControl: 
        Type: AWS::CloudFront::OriginAccessControl
        Properties: 
          OriginAccessControlConfig:
            Description: Access Control
            Name: !Sub "${SystemName}-${EnvName}-${BucketName}-OAC"
            OriginAccessControlOriginType: s3
            SigningBehavior: always
            SigningProtocol: sigv4 
      CloudFrontDistribution:
        Type: "AWS::CloudFront::Distribution"
        Properties:
          DistributionConfig:
            WebACLId: !ImportValue WebACLARN # WAFにアタッチ
            Origins:
            - DomainName: !GetAtt S3Bucket.RegionalDomainName
              Id: !Sub "${SystemName}-${EnvName}-S3origin"
              OriginAccessControlId: !GetAtt CloudFrontOriginAccessControl.Id 
              S3OriginConfig: 
                OriginAccessIdentity: ""
            DefaultCacheBehavior: 
              TargetOriginId: !Sub "${SystemName}-${EnvName}-S3origin" 
              ViewerProtocolPolicy: allow-all
              AllowedMethods:
              - GET
              - HEAD
              Compress: true
              ForwardedValues:
                Cookies:
                  Forward: none
                QueryString: false
            HttpVersion: http2
            Enabled: true  
          Tags:
            - Key: Name
              Value: !Sub ${SystemName}-${EnvName}-cf
            - Key: Env
              Value: !Sub ${EnvName}
    #------------------------------------------------------------
    # Output Parameters
    #------------------------------------------------------------
    Outputs:
      S3Bucket:
        Value: !Ref S3Bucket
        Export:
          Name: !Sub ${EnvName}-${BucketName}
      CloudFrontDistribution:
        Value: !Ref CloudFrontDistribution
        Export:
          Name: !Sub ${EnvName}-cf
    ```
