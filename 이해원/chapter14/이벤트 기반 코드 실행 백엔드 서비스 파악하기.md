# 1. 이벤트 기반 코드 실행 서비스, AWS 람다란?

AWS 람다는 서버리스 서비스로 서버를 구축하지 않고도 작성한 코드를 실행할 수 있는 이벤트 구동형 프로그램 실행환경이다.

넒은 의미로 보면 서버리스이고, 명확하게 표현하면 FaaS(Functions-as-a-service)로 볼 수 있다.

## FaaS

- = 서버리스 아키텍처
- FaaS를 사용하면 직접 개발한 개별 함수를 클라우드에서 실행할 수 있으며 필요에 따라 다른 함수와 결합해 애플리케이션을 개발할 수 있다.
- 서버 준비/관리에 걸리는 시간을 생략할 수  있다.

## IaaS(Infrastructure as a service)

하드웨어 리소스를 제공하며, 이를 바탕으로 애플리케이션 개발

ex) 아마존 EC2

## PasS(Platform as a service)

애플리케이션을 개발/테스트/배포하기 위한 환경 제공

ex) AWS 엘라스틱 빈스토크, S3

## SaaS(Software as s service)

최종 사용자를 위한 소프트웨어, 사용자는 웹사이트/애플리케이션을 통해 소프트웨어에 접근

ex) 구글 독스 

# 2. 이벤트 기반 코드 실행 서비스, AWS 람다 살펴보기

함수는 특정 이벤트에 대한 핸들러로 구성

이벤트가 발생하면 핸들러가 실행되어 코드를 실행하는 구조

## 2.1 AWS 람다 이점

- 비용 절감
    - 코드 실행 시간, 요청 수에 따라 비용 청구
    - 별도 서버를 준비할 필요가 없음
- 안전한 실행 환경
- 장애 위험 부담 감소
    - AWS가 서버 관리를 담당하므로 람다 함수 하나에 장애가 발생해도 AWS가 대응
- 다양한 프로그래밍 언어 제공
- 다른 AWS 서비스와의 연동
    - S3 웹 호스팅을 구현하거나 서버리스 웹 호스팅 구현
    - 다이나모 DB의 데이터를 가져와 웹사이트를 호스팅하는 S3 또는 앰플리파이에 출력할 수 있다. (동적 표시)

## 2.1 AWS 람다 구성 요소

### AWS 람다 함수 새로 작성

새로 작성하는 함수에 대해서는 함수 이름, 런타임, 아키텍처, 권한으로 구성

- 런타임: 함수에서 사용하는 프로그래밍 언어 또는 프레임워크의 버전
- 아키텍처: 컴퓨터 프로세서 유형 선택
    - x86_64, arm64
- 권한: 각 서비스에 대한 권한 부여 → IAM 서비스

### AWS 람다 함수 블루프린트 사용

블루프린트를 사용하면 람다 함수에서 샘플 코드를 제공받아 더 간편하게 함수를 작성할 수 있다.

블루프린트를 선택하면 자동으로 런타임, 아키텍처가 결정된다.

- 함수 이름
- 블루프린트 이름
- 권한

### AWS 람다 함수 컨테이너 이미지

컨테이너 이미지는 람다 함수를 컨테이너화하는 것으로 ECR에 푸시한 이미지를 AWS에 배포할 수 있다.

기존 람다 함수 사용 시 외부 라이브러리나 미들웨어를 도입하는 경우, 라이브러리 버전이 일치해야 하거나 특정 미들웨어를 도입해야 하는 등의 문제가 있을 수 있는데 이런 문제를 해결할 수 있다.

- 함수 이름
- 컨테이너 이미지 URI
    - 사전에 ECR로 이미지 푸시 필요
- 아키텍처
- 권한

# 3. AWS 람다 함수 생성해보기

- lambda.yml
    
    ```yaml
    AWSTemplateFormatVersion: "2010-10-09"
    Description: Create Lambda
    # ------------------------------------------------------------#
    # Input Parameters
    # ------------------------------------------------------------# 
    Parameters:
      SystemName:
        Description: "System name of each resource names."
        Type: String
        Default: "gr"
      EnvName:
        Description: "Environment name of each resource names."
        Type: String
        Default: "product"
    
    # ------------------------------------------------------------#
    #  Create Lambda Role
    # ------------------------------------------------------------#
    Resources : 
      LambdaIAMRole:
        Type: AWS::AWS::IAM::Role
        DeletionPolicy: Delete
        Properties:
          # 파라미터(SystemName, EnvName)를 조합하여 역할 이름 동적 생성
          RoleName: !Sub ${SystemName}-${EnvName}-lambdarole
          # AWS Lambda 서비스가 이 역할을 위임받아 사용할 수 있도록 신뢰 관계 설정
          AssumeRolePolicyDocument: 
            Version: "2012-10-17"
            Statement: 
              - Effect: "Allow"
                Principal: 
                  Service: 
                    - "lambda.amazonaws.com"
                Action: 
                  - "sts:AssumeRole"
          Path: "/"
          # Lambda 실행에 필요한 기본 관리형 정책 연결
          ManagedPolicyArns:
            - "arn:aws:iam::aws:policy/AWSLambda_FullAccess"
    
    # ------------------------------------------------------------#
    #  Create Lambda
    # ------------------------------------------------------------#
      LambdaFunction:
        Type: AWS::Lambda::Function
        Properties:
          FunctionName: !Sub ${SystemName}-${EnvName}-function
          # 인라인 코드로 간단한 Python 함수 정의 (index.py 파일로 생성됨)
          Code:
            ZipFile: |
              import json
    
              def lambda_handler(event, context):
                  # TODO implement
                  return {
                      'statusCode': 200,
                      'body': json.dumps('Hello from Lambda!')
                  }
          # 실행할 파일명과 함수명 지정 (index.py의 lambda_handler 함수)
          Handler: index.lambda_handler
          # 위에서 생성한 IAM 역할의 ARN을 함수에 바인딩
          Role: !GetAtt LambdaIAMRole.Arn
          Runtime: python3.12
          Timeout: 30
    ```
    
1. 스택 생성
2. aws 람다 콘솔에서 생성된 람다 함수 확인
3. 코드 실행
    - 람다 함수를 생성하면 함수 개요가 출력되며 현재 람다 함수에서 사용되는 람다 계층과 연동하는 aws 서비스를 확인할 수 있다.
    - 코드 카테고리 클릭 → 파이썬 코드 확인
    - [Test] 클릭 → 람다 함수의 이벤트 생성 or 기존 이벤트 선택
4. 람다 함수의 이벤트 생성
5. 람다 함수를 실행해 결과 확인
