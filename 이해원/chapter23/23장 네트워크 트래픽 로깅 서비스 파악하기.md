# 23장 네트워크 트래픽 로깅 서비스 파악하기

# 1. 네트워크 트래픽 로깅 서비스, VPC 플로우 로그란?
> https://docs.aws.amazon.com/ko_kr/vpc/latest/userguide/flow-logs.html
>
VPC에서 전송되고 수신되는 트래픽에 대한 정보를 수집하는 기능

수집한 트래픽은 S3, 클라우드워치 로그 등에 보존해 확인할 수 있다.

## 동작 원리

1. 사용자는 VPC를 거쳐 서브넷에 있는 EC2 인스턴스에 접속
2. 접속한 결과를 VPC 플로우 로그는 하나의 로그로 가공해 S3에 보존

## 사용 사례

- 보안 진단
- 네트워크 통신 문제 조사: 트래픽 모니터링 → 서버에 접속 불가능한 경우 트래픽이 어디까지 도달하는지 등 확인
- 아마존 가드듀티에서 위협 탐지를 위한 데이터 소스로 활용

# 2. VPC 플로우 로그 살펴보기

## VPC 플로우 로그 필드

| 필드명 | 의미 | 설명 |
| --- | --- | --- |
| **version** | 로그 버전 | VPC 플로우 로그 포맷의 버전 (기본값 2) |
| **account-id** | 계정 ID | 네트워크 인터페이스(ENI) 소유자의 AWS 계정 ID |
| **interface-id** | 인터페이스 ID | 트래픽이 기록된 탄력적 네트워크 인터페이스(ENI)의 ID |
| **srcaddr** | 출발지 IP | 트래픽의 출발지 IP 주소 (IPv4 또는 IPv6) |
| **dstaddr** | 목적지 IP | 트래픽의 목적지 IP 주소 (IPv4 또는 IPv6) |
| **srcport** | 출발지 포트 | 트래픽의 출발지 포트 번호 |
| **dstport** | 목적지 포트 | 트래픽의 목적지 포트 번호 |
| **protocol** | 프로토콜 | IANA 프로토콜 번호 (예: `6`=TCP, `17`=UDP, `1`=ICMP) |
| **packets** | 패킷 수 | 캡처 창(Capture Window) 동안 전송된 패킷의 총 개수 |
| **bytes** | 바이트 수 | 캡처 창 동안 전송된 총 바이트 수 |
| **start** | 시작 시간 | 트래픽 캡처 창의 시작 시간 (Unix 타임스탬프) |
| **end** | 종료 시간 | 트래픽 캡처 창의 종료 시간 (Unix 타임스탬프) |
| **action** | 동작 결과 | 보안 그룹 및 네트워크 ACL에 의한 트래픽 처리 결과 (`ACCEPT` 또는 `REJECT`) |
| **log-status** | 로그 상태 | 로그 기록의 상태 (`OK`: 정상 기록, `NODATA`: 트래픽 없음, `SKIPDATA`: 일부 로그 누락) |

**srcaddr, dstaddr (출발지 및 목적지 IP)**

- 비정상적인 IP(해외 IP, 악성 IP 등)와의 통신 여부 확인
- 퍼블릭 접근이 불필요한 리소스(예: Private Subnet의 RDS)가 외부망과 통신하는지 등 내부 리소스 간 잘못된 통신 패턴 점검

**srcport, dstport (출발지 및 목적지 포트)**

- 인가되지 않은 포트(예: 22(SSH), 3389(RDP), 3306(DB))로의 무단 접근 시도 확인
- 애플리케이션에서 사용하지 않는 포트를 통한 비정상적인 데이터 유출 시도 감지

**action (동작 결과: ACCEPT / REJECT)**

- **REJECT:** 보안 그룹(SG)이나 네트워크 ACL에 의해 차단된 트래픽으로, 포트 스캔이나 무차별 대입 공격(Brute-force) 등의 악의적 접근 시도 파악
- **ACCEPT:** 실수로 보안 규칙이 넓게 열려 있어(예: 0.0.0.0/0 허용) 차단되어야 할 트래픽이 허용되고 있는지 보안 취약점 점검

**bytes, packets (전송된 바이트 및 패킷 수)**

- 특정 IP에서 비정상적으로 많은 패킷이 들어오는 경우 DDoS 공격 의심
- 외부로 비정상적으로 큰 바이트가 전송되는 경우 내부 데이터 유출(Data Exfiltration) 의심

**protocol (프로토콜)**

- 서비스에 불필요한 프로토콜(예: 웹 서버에 과도한 ICMP(Ping) 요청)이 유입되는지 확인하여 프로토콜 기반 공격 탐지

**interface-id (인터페이스 ID)**

- 이상 트래픽이나 공격이 감지되었을 때, 해당 트래픽이 유입된 정확한 AWS 리소스(특정 EC2 인스턴스, ALB 등)를 추적하고 격리하는 데 사용

- Security_Group.yml
    
    ```yaml
    AWSTemplateFormatVersion: "2010-09-09"
    Description: Create Security Group
    # ------------------------------------------------------------#
    # Input Parameters
    # ------------------------------------------------------------# 
    Parameters:
      SystemName:
        Description: "System name of each resource names."
        Type: String
        Default: "gr"
      EnvName:
        Description: "Environment name of each resource names."
        Type: String
        Default: "product"
    # ------------------------------------------------------------#
    #  Create Security Group
    # ------------------------------------------------------------#
    Resources:
      EC2SecurityGroup:
        Type: AWS::EC2::SecurityGroup # 보안 그룹을 생성
        Properties:
          GroupName: !Sub ${SystemName}-${EnvName}-ec2-sg # 보안 그룹 이름을 지정
          GroupDescription: !Sub ${SystemName}-${EnvName}-ec2-sg # 보안 그룹 설명
          SecurityGroupIngress: # 허용할 IP 주소 설정
                - IpProtocol: tcp
                  FromPort: 22
                  ToPort: 22
                  CidrIp: 0.0.0.0/0
          VpcId:
            Fn::ImportValue: !Sub ${EnvName}-vpc
          Tags: 
            - Key: Name
              Value: !Sub ${SystemName}-${EnvName}-ec2-sg
            - Key: Env
              Value: !Sub ${EnvName}
    # ------------------------------------------------------------
    # Output Parameters
    # ------------------------------------------------------------
    Outputs:
    # Security Groups
      EC2SecurityGroup:
        Value: !Ref EC2SecurityGroup
        Export:
          Name: !Sub ${EnvName}-ec2-sg
    ```

    ```yaml
    AWSTemplateFormatVersion: "2010-09-09"
    Description: Create EC2
    # ------------------------------------------------------------#
    # Input Parameters
    # ------------------------------------------------------------# 
    Parameters:
      SystemName:
        Description: "System name of each resource names."
        Type: String
        Default: "gr"
      EnvName:
        Description: "Environment name of each resource names."
        Type: String
        Default: "product"
      KeyPairName: 
        Description: gr-product-ec2 EC2 Key Pair
        Type: String
        Default: gr-product-ec2-key
      EC2AMI: 
        Description: gr-product-ec2 EC2 AMI
        Type: String
        Default: ami-02d081c743d676996
      InstanceType:
        Description: gr-product-ec2 EC2 instance type
        Type: String
        Default: t3.micro
    # ------------------------------------------------------------#
    #  Create EC2 Instance 
    # ------------------------------------------------------------#
    Resources:
      NewKeyPair:
        Type: AWS::EC2::KeyPair
        Properties:
          KeyName: !Ref KeyPairName
      EC2Instance:
        Type: AWS::EC2::Instance
        Properties:
          ImageId: !Ref EC2AMI
          InstanceType: !Ref InstanceType
          KeyName: !Ref NewKeyPair
          NetworkInterfaces:
            - DeviceIndex: 0
              SubnetId: { "Fn::ImportValue": !Sub "${EnvName}-public-subnet-1a" }
              GroupSet:
              - Fn::ImportValue: !Sub ${EnvName}-ec2-sg
              AssociatePublicIpAddress: true
          BlockDeviceMappings:
            - DeviceName: /dev/xvda
              Ebs:
                VolumeSize: 100
                VolumeType: gp3
                Encrypted : true
          Tags: 
            - Key: Name
              Value: !Sub ${SystemName}-${EnvName}-ec2
            - Key: Env
              Value: !Sub ${EnvName}
    # ------------------------------------------------------------
    # Output Parameters
    # ------------------------------------------------------------
    Outputs:
    # EC2
      EC2Instance:
        Value: !Ref EC2Instance
        Export:
          Name: !Sub ${EnvName}-ec2
    ```
    
- VPC-Flow-Logs.yml
    
    ```yaml
    AWSTemplateFormatVersion: "2010-09-09"
    Description: Create VPC Flow Logs
    # ------------------------------------------------------------#
    # Input Parameters
    # ------------------------------------------------------------# 
    Parameters:
      SystemName:
        Description: "System name of each resource names."
        Type: String
        Default: "gr"
      EnvName:
        Description: "Environment name of each resource names."
        Type: String
        Default: "product"
      BucketName:
        Description: "Bucket name."
        Type: String
        Default: "bucket"
      VpcId:
        Type: AWS::EC2::VPC::Id
        Description: Select the VPC
    
    # ------------------------------------------------------------#
    #  Create VPC Flow Logs Bucket
    # ------------------------------------------------------------#
    Resources:
      FlowLogsBucket:
        Type: "AWS::S3::Bucket"
        Properties:
          BucketName: !Sub ${SystemName}-${EnvName}-${BucketName}
          PublicAccessBlockConfiguration:
            BlockPublicAcls: true
            BlockPublicPolicy: true
            IgnorePublicAcls: true
            RestrictPublicBuckets: true
          LifecycleConfiguration:
            Rules:
              - Id: !Sub ${SystemName}-${EnvName}-${BucketName}-lifecycle
                Status: Enabled
                ExpirationInDays: 365
          Tags:
            - Key: Name
              Value: !Sub ${SystemName}-${EnvName}-${BucketName}
    
    # ------------------------------------------------------------#
    #  Create VPC Flow Logs
    # ------------------------------------------------------------#
      VPCFlowlogs:
        Type: AWS::EC2::FlowLog
        Properties:
          LogDestinationType: s3
          LogDestination: !GetAtt FlowLogsBucket.Arn
          ResourceId:
            Ref: VpcId
          ResourceType: VPC
          TrafficType: ALL
          Tags:
            - Key: Name
              Value: !Sub ${SystemName}-${EnvName}-flowlogs
    ```
