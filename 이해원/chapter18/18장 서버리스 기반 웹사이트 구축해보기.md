# 18장. 서버리스 기반 웹사이트 구축해보기

# 1. 서버리스 기반 웹사이트 구성도 이해하기

서버리스 기반 웹사이트는 실시간 처리 능력, 확장성, 이벤트 중심의 애플리케이션에 적합하다.

- 즉각적인 사용자 상호작용 기능을 제공하는 서비스
    - 실시간 투표 시스템
- 이벤트 기반 애플리케이션
    - 게시판
    - 온라인 학습 플랫폼

## 구축할 환경

1. AWS 앰플리파이 → HTML과 JS 파일을 이용해 프론트 처리 수행
2. API 게이트웨이, 람다, 다이나모DB → 백엔드 처리
    - 다이나모DB에 입력된 데이터를 AWS 앰플리파이 웹 호스팅을 통해 사용자에게 출력

# 2. 클라우드포메이션으로 리소스 생성하기

- DynamoDB.yml
    
    ```yaml
    AWSTemplateFormatVersion: "2010-09-09"
    Description: Create API Gateway & Lambda
    # ------------------------------------------------------------#
    # Input Parameters
    # ------------------------------------------------------------# 
    Parameters:
      SystemName:
        Description: "System name of each resource names."
        Type: String
        Default: "gr"
      EnvName:
        Description: "Environment name of each resource names."
        Type: String
        Default: "product"
    # ------------------------------------------------------------#
    #  Create REST API 
    # ------------------------------------------------------------#
    Resources :
      MyDynamoDBTable:
        Type: AWS::DynamoDB::Table # DynamoDB 테이블의 Id, name, description 항목은 콘솔 화면에서 별도로 생성하도록 합시다.
        Properties:
          TableName: !Sub ${SystemName}-${EnvName}-db
          AttributeDefinitions:
            - AttributeName: id # 파티션 키
              AttributeType: S  # 파티션 키는 문자열
          KeySchema:
            - AttributeName: id
              KeyType: HASH
          BillingMode: PAY_PER_REQUEST  # 온디맨드 모드
          Tags:
            - Key: Name
              Value: !Sub ${SystemName}-${EnvName}-dynamoDB
            - Key: Env
              Value: !Sub ${EnvName}
    ```

# 3. 데이터를 관리하는 다이나모DB 테이블 항목 생성하기

1. 클라우드포메이션 스택 생성 (기본값 유지)
2. 다이나모DB 테이블 항목 생성
    1. 생성한 테이블 선택 → [작업] → [항목 탐색] → [항목 생성]
3. 항목 생성
    1. 파티션 키: id
    2. 추가 속성: name, description
    3. [새 속성 추가]에서 문자열 클릭

# 4. 웹사이트를 호스팅하는 AWS 앰플리파이 생성하기

AWS 앰플리파이를 생성하기 앞서, 자바스크립트 파일의 코드를 수정해 API 게이트웨이를 연동시켜야 한다.

1. API 게이트웨이 URL 확인
    1. [스테이지] → [URL 호출]
2. index.js에 API 게이트웨이 URL 입력
    - index.js
        
        ```jsx
        // send data from s3 -> lambda(dynamoDB)
        async function sendDataToLambda() {
            try {
                const htmlid = document.getElementById('id').value;
                const htmlname = document.getElementById('name').value;
                const htmldescription = document.getElementById('description').value;
        
                const dataToSend = {
                    id: htmlid,
                    name: htmlname,
                    description: htmldescription
                };
        
                const response = await axios.post('API Gateway URL 입력', dataToSend);
                console.log('Response from Lambda:', response.data);
        
            } catch (error) {
                console.error('Error sending data:', error);
            }
        }
        
        // get data from lambda(dynamoDB)
        async function getDataToLambda() {
            try {
                const response = await axios.get('API Gateway URL 입력');
        
                const getData = response.data;
        
                const listContainer = document.getElementById('responseData');
        
                getData.forEach(item => {
                const listItem = document.createElement('p');
                listItem.textContent = `ID: ${item.id}, Name: ${item.name}, Description: ${item.description}`;
                listContainer.appendChild(listItem);
            });
            } catch (error) {
                console.error('Error reading data:', error);
            }
        }
        getDataToLambda();
        ```
        
    - index.html
        
        ```jsx
        <!DOCTYPE html>
        <html lang="ko">
        <head>
          <meta charset="UTF-8">
          <title>test</title>
        </head>
        <body>
        <!-- GetData -->
            <h1>List</h1>
            <div id="responseData"></div>
        
         <!-- InputData -->
            <div>
                <h1>Input</h1>
                    <table>
                        <tr>
                            <td><input type="text" id="id" placeholder="ID"></td>
                            <td><input type="text" id="name" placeholder="Name"></td>
                            <td><input type="text" id="description" placeholder="Description"></td>
                        </tr>
                    </table>
                    <button onclick="sendDataToLambda()">Send Data</button>
            </div>
          <script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
          <script src="index.js"></script>
        </body>
        </html>
        ```
        
3. AWS 앰플리파이 콘솔 화면 [앱 배포] 클릭
4. AWS 앰플리파이 배포 진행
    1. [Git 없이 배포] → 앱 이름 입력 → 업로드 방식: 드래그 앤 드롭 → zip 형태로 업로드 →  [저장 및 배포]
5. 배포한 웹 호스팅 사이트 확인, 도메인으로 접근
